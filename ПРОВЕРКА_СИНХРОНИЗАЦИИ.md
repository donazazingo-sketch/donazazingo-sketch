# Проверка синхронизации данных

## Проблема: Данные не синхронизируются между устройствами

Если данные все еще различаются на разных устройствах, проверьте следующие пункты:

## ✅ Шаг 1: Проверка переменных окружения в Vercel

1. Откройте Vercel Dashboard → ваш проект
2. Перейдите в **Settings** → **Environment Variables**
3. Убедитесь, что добавлены обе переменные:
   - `NEXT_PUBLIC_SUPABASE_URL` (должен начинаться с `https://`)
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` (длинная строка)

4. **ВАЖНО**: Если вы только что добавили переменные:
   - Перейдите в **Deployments**
   - Нажмите **Redeploy** на последнем деплое
   - Подождите завершения сборки

## ✅ Шаг 2: Проверка таблиц в Supabase

1. Откройте Supabase Dashboard: https://supabase.com/dashboard
2. Выберите ваш проект
3. Перейдите в **Table Editor** (слева)
4. Убедитесь, что существуют таблицы:
   - `stores`
   - `category_names`

5. Если таблиц нет:
   - Перейдите в **SQL Editor**
   - Выполните SQL из файла `НАСТРОЙКА_SUPABASE.md`

## ✅ Шаг 3: Проверка API в браузере

1. Откройте ваш сайт на Vercel
2. Нажмите `F12` (открыть DevTools)
3. Перейдите на вкладку **Console**
4. Проверьте наличие ошибок:
   - Если видите "Missing Supabase environment variables" → переменные не настроены
   - Если видите ошибки API → проверьте таблицы в Supabase

5. Перейдите на вкладку **Network**
6. Обновите страницу (`F5`)
7. Найдите запросы к `/api/stores` и `/api/category-names`
8. Проверьте статус ответа:
   - `200 OK` → все работает
   - `500 Error` → проблема с Supabase или таблицами

## ✅ Шаг 4: Проверка Row Level Security (RLS)

1. В Supabase Dashboard перейдите в **Authentication** → **Policies**
2. Убедитесь, что для таблиц `stores` и `category_names` созданы политики:
   - "Allow public read access" (SELECT)
   - "Allow public insert access" (INSERT)
   - "Allow public update access" (UPDATE)
   - "Allow public delete access" (DELETE)

3. Если политик нет, выполните SQL из `НАСТРОЙКА_SUPABASE.md`

## ✅ Шаг 5: Тест синхронизации

1. Откройте сайт на **двух разных устройствах** (или в двух разных браузерах)
2. На первом устройстве:
   - Добавьте новую позицию
   - Измените название категории
3. На втором устройстве:
   - Обновите страницу (`F5`)
   - Данные должны появиться автоматически

4. Если данные не синхронизируются:
   - Проверьте консоль браузера на ошибки
   - Убедитесь, что переменные окружения добавлены в Vercel
   - Убедитесь, что проект пересобран после добавления переменных

## 🔧 Быстрое решение

Если ничего не помогает, выполните полную настройку заново:

1. **В Supabase:**
   ```sql
   -- Удалите старые таблицы (если есть)
   DROP TABLE IF EXISTS stores CASCADE;
   DROP TABLE IF EXISTS category_names CASCADE;
   
   -- Создайте таблицы заново
   CREATE TABLE stores (
     id TEXT PRIMARY KEY,
     name TEXT NOT NULL,
     products JSONB DEFAULT '[]'::jsonb,
     created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
     updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
   );
   
   CREATE TABLE category_names (
     id SERIAL PRIMARY KEY,
     category1 TEXT NOT NULL DEFAULT 'Електроніка',
     category2 TEXT NOT NULL DEFAULT 'Аксесуари',
     category3 TEXT NOT NULL DEFAULT 'Послуги',
     updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
   );
   
   -- Включите RLS
   ALTER TABLE stores ENABLE ROW LEVEL SECURITY;
   ALTER TABLE category_names ENABLE ROW LEVEL SECURITY;
   
   -- Создайте политики
   CREATE POLICY "Allow public read access" ON stores FOR SELECT USING (true);
   CREATE POLICY "Allow public insert access" ON stores FOR INSERT WITH CHECK (true);
   CREATE POLICY "Allow public update access" ON stores FOR UPDATE USING (true);
   CREATE POLICY "Allow public delete access" ON stores FOR DELETE USING (true);
   
   CREATE POLICY "Allow public read access" ON category_names FOR SELECT USING (true);
   CREATE POLICY "Allow public insert access" ON category_names FOR INSERT WITH CHECK (true);
   CREATE POLICY "Allow public update access" ON category_names FOR UPDATE USING (true);
   ```

2. **В Vercel:**
   - Удалите старые переменные окружения
   - Добавьте их заново с правильными значениями
   - Пересоберите проект (Redeploy)

3. **Проверьте:**
   - Откройте сайт
   - Откройте консоль браузера (F12)
   - Не должно быть ошибок

## 📞 Если проблема остается

Пришлите:
1. Скриншот ошибок из консоли браузера (F12 → Console)
2. Скриншот переменных окружения в Vercel (скройте значения)
3. Скриншот таблиц в Supabase Table Editor
