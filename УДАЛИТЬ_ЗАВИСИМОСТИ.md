# Как удалить старые зависимости

## Способ 1: Через PowerShell (рекомендуется)

Откройте PowerShell в папке проекта и выполните:

```powershell
# Перейдите в папку проекта
cd C:\Users\user\inventory-tracker

# Удалите папку node_modules
Remove-Item -Recurse -Force node_modules

# Удалите файл package-lock.json
Remove-Item -Force package-lock.json

# Теперь установите новые зависимости
npm install
```

## Способ 2: Через Command Prompt (CMD)

```cmd
cd C:\Users\user\inventory-tracker
rmdir /s /q node_modules
del package-lock.json
npm install
```

## Способ 3: Через Проводник Windows

1. Откройте папку `C:\Users\user\inventory-tracker`
2. Удалите папку `node_modules` (если она есть)
3. Удалите файл `package-lock.json` (если он есть)
4. Откройте PowerShell в этой папке и выполните: `npm install`

## Способ 4: Через npm (автоматически)

```powershell
cd C:\Users\user\inventory-tracker
npm ci --force
```

Или просто:

```powershell
cd C:\Users\user\inventory-tracker
npm install --force
```

## После удаления:

После выполнения команд установятся новые зависимости из обновленного `package.json`.

---

**Важно:** Убедитесь, что вы находитесь в правильной папке (`C:\Users\user\inventory-tracker`) перед выполнением команд!
