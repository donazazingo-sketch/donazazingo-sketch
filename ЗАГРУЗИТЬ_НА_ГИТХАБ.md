# Команды для загрузки изменений на GitHub

Выполните эти команды в PowerShell или Command Prompt в папке `C:\Users\user\inventory-tracker`:

## Если Git еще не установлен:

1. Скачайте Git: https://git-scm.com/download/win
2. Установите Git
3. Перезапустите терминал

## Команды для загрузки на GitHub:

```powershell
# Перейдите в папку проекта
cd C:\Users\user\inventory-tracker

# Инициализируйте git (если еще не сделано)
git init

# Добавьте все файлы
git add .

# Создайте коммит с описанием изменений
git commit -m "Добавлено сохранение данных в localStorage и изменение 'магазин' на 'позицію'"

# Подключите ваш GitHub репозиторий (ЗАМЕНИТЕ YOUR_USERNAME на ваш GitHub username!)
git remote add origin https://github.com/YOUR_USERNAME/donazazingo-sketch.git

# Если remote уже существует, используйте вместо этого:
# git remote set-url origin https://github.com/YOUR_USERNAME/donazazingo-sketch.git

# Переименуйте ветку в main (если нужно)
git branch -M main

# Загрузите на GitHub
git push -u origin main
```

## Если репозиторий уже существует на GitHub:

Если вы уже загружали код ранее, используйте:

```powershell
cd C:\Users\user\inventory-tracker

# Добавьте все изменения
git add .

# Создайте коммит
git commit -m "Обновление: сохранение данных в localStorage, изменение текста на 'позицію'"

# Загрузите изменения
git push
```

✅ Добавлено сохранение названий категорий в localStorage
✅ Добавлено сохранение всех позиций и товаров в localStorage
✅ Данные теперь сохраняются при обновлении страницы

---

**Важно:** Замените `YOUR_USERNAME` на ваш реальный GitHub username перед выполнением команд!
