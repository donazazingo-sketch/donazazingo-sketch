# Инструкция по загрузке приложения в GitHub

## Шаг 1: Создайте новый репозиторий на GitHub

1. Перейдите на [GitHub.com](https://github.com) и войдите в свой аккаунт
2. Нажмите на иконку "+" в правом верхнем углу
3. Выберите "New repository"
4. Назовите репозиторий: `donazazingo-sketch`
5. Выберите Public или Private
6. **НЕ** ставьте галочки на "Initialize with README", ".gitignore" или "License" (они уже есть)
7. Нажмите "Create repository"

## Шаг 2: Инициализируйте Git и загрузите код

Откройте терминал (PowerShell или Command Prompt) в папке `inventory-tracker` и выполните следующие команды:

```bash
# Инициализация git репозитория
git init

# Добавление всех файлов
git add .

# Создание первого коммита
git commit -m "Initial commit: Inventory Tracker app"

# Добавление удаленного репозитория (замените YOUR_USERNAME на ваш GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/donazazingo-sketch.git

# Переименование ветки в main (если нужно)
git branch -M main

# Загрузка на GitHub
git push -u origin main
```

**Важно:** Замените `YOUR_USERNAME` на ваш реальный GitHub username!

## Шаг 3: Альтернативный способ через GitHub Desktop

Если у вас установлен GitHub Desktop:

1. Откройте GitHub Desktop
2. Нажмите "File" → "Add Local Repository"
3. Найдите папку `inventory-tracker`
4. Нажмите кнопку "Publish repository"
5. Выберите ваш GitHub аккаунт и название репозитория `donazazingo-sketch`
6. Нажмите "Publish repository"

## Пример команд (замените username)

Если ваш GitHub username, например, `john-doe`, команды будут выглядеть так:

```bash
git init
git add .
git commit -m "Initial commit: Inventory Tracker app"
git remote add origin https://github.com/john-doe/donazazingo-sketch.git
git branch -M main
git push -u origin main
```

## Если Git не установлен

1. Скачайте Git с [git-scm.com](https://git-scm.com/download/win)
2. Установите Git
3. Перезапустите терминал
4. Выполните команды из Шага 2

## Проверка

После выполнения команд откройте ваш репозиторий на GitHub:
`https://github.com/YOUR_USERNAME/donazazingo-sketch`

Вы должны увидеть все файлы вашего приложения!

## Дополнительно: Развертывание на Vercel

Поскольку это Next.js приложение, вы можете легко развернуть его на Vercel:

1. Перейдите на [Vercel.com](https://vercel.com)
2. Войдите через GitHub
3. Нажмите "New Project"
4. Импортируйте репозиторий `donazazingo-sketch`
5. Нажмите "Deploy"

Ваше приложение будет доступно по адресу `https://donazazingo-sketch.vercel.app`
