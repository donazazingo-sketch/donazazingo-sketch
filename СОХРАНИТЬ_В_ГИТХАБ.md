# Как сохранить изменения в GitHub

## Шаг 1: Установите Git (если еще не установлен)

1. Перейдите на сайт: https://git-scm.com/download/win
2. Скачайте установщик Git для Windows
3. Запустите установщик и следуйте инструкциям (можно оставить все настройки по умолчанию)
4. **ВАЖНО:** После установки перезапустите PowerShell или Command Prompt

## Шаг 2: Выполните команды для загрузки на GitHub

Откройте PowerShell или Command Prompt и выполните команды:

```powershell
# Перейдите в папку проекта
cd C:\Users\user\inventory-tracker

# Проверьте статус (если репозиторий уже инициализирован)
git status

# Если репозиторий еще не создан, инициализируйте его
git init

# Добавьте все файлы
git add .

# Создайте коммит с описанием изменений
git commit -m "Добавлено сохранение значений товаров в localStorage"

# Если репозиторий еще не подключен к GitHub, подключите его
# ЗАМЕНИТЕ YOUR_USERNAME на ваш GitHub username!
git remote add origin https://github.com/YOUR_USERNAME/donazazingo-sketch.git

# Если репозиторий уже подключен, используйте вместо этого:
# git remote set-url origin https://github.com/YOUR_USERNAME/donazazingo-sketch.git

# Переименуйте ветку в main (если нужно)
git branch -M main

# Загрузите изменения на GitHub
git push -u origin main
```

## Если репозиторий уже существует на GitHub:

Если вы уже загружали код ранее, используйте более простые команды:

```powershell
cd C:\Users\user\inventory-tracker

# Добавьте все изменения
git add .

# Создайте коммит
git commit -m "Обновление: улучшено сохранение значений товаров в localStorage"

# Загрузите изменения
git push
```

## Альтернативный способ: GitHub Desktop

Если не хотите использовать командную строку:

1. Скачайте GitHub Desktop: https://desktop.github.com/
2. Установите и откройте GitHub Desktop
3. File → Add Local Repository
4. Выберите папку: `C:\Users\user\inventory-tracker`
5. Если репозиторий уже подключен:
   - Все изменения будут видны в интерфейсе
   - Введите описание изменений внизу
   - Нажмите "Commit to main"
   - Нажмите "Push origin"
6. Если репозиторий еще не подключен:
   - Нажмите "Publish repository"
   - Название: `donazazingo-sketch`
   - Нажмите "Publish repository"
