# Обновление зависимостей для устранения предупреждений

## Что было изменено:

✅ **Next.js**: обновлен с 14.2.18 до 15.1.3 (поддерживает ESLint 9)
✅ **ESLint**: обновлен с 8.57.1 до 9.18.0 (последняя версия)
✅ **eslint-config-next**: обновлен до 15.1.3 (совместим с Next.js 15)
✅ **Конфигурация ESLint**: переведена на новый формат (flat config)

## Как применить изменения:

1. **Удалите старые зависимости:**
```powershell
cd C:\Users\user\inventory-tracker
Remove-Item -Recurse -Force node_modules
Remove-Item -Force package-lock.json
```

2. **Установите обновленные зависимости:**
```powershell
npm install
```

3. **Проверьте, что все работает:**
```powershell
npm run build
npm run lint
```

4. **Загрузите изменения на GitHub:**
```powershell
git add .
git commit -m "Обновлены зависимости: Next.js 15, ESLint 9 - устранены предупреждения"
git push
```

После этого Vercel автоматически пересоберет проект с новыми зависимостями, и предупреждения должны исчезнуть.

## Изменения в конфигурации:

- Удален файл `.eslintrc.json` (старый формат)
- Создан файл `eslint.config.mjs` (новый flat config формат для ESLint 9)
- Добавлена зависимость `@eslint/eslintrc` для совместимости

## Примечание:

Если после обновления возникнут проблемы, можно вернуться к предыдущим версиям, но предупреждения останутся. Они не критичны и не влияют на работу приложения.
